**Fokus v1.0.1** fuer Windows (x64). Seitenblocker mit Selbstbindung:
Domain eintragen, `beispiel.de` blockt die ganze Seite, `sub.beispiel.de`
exakt diesen Host. Rueckgaengig nur innerhalb von 60 Sekunden, danach ist
die Sperre dauerhaft.

## Behoben gegenueber 1.0.0

Der 1.0.0-Installer enthielt eine WebView2Loader.dll der falschen
Prozessorarchitektur. Das Fokus-Fenster startete deshalb mit dem Fehler
0x8007000B ("Es wurde versucht, eine Datei mit einem falschen Format zu
laden"). In 1.0.1 ist das behoben; der Build prueft die Architektur aller
Binaerdateien jetzt automatisch.

## Installation

`Fokus-Setup-x64.exe` ausfuehren. Eine vorhandene 1.0.0 wird direkt
ueberinstalliert, Einstellungen und bestehende Sperren bleiben erhalten.
Pruefsumme in `SHA256SUMS`.
